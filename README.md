# 托卡马克粒子模拟 · Tokamak Particle Simulation

纯前端（Three.js + 本地物理引擎）的托卡马克带电粒子约束模拟。
无需任何后端 / Python，浏览器本地完成全部物理计算。

## 运行方式

```bash
cd D:\VSCode\Tokamak_web
node serve.js            # 默认端口 8081
```

然后浏览器打开 **http://localhost:8081**

> 说明：由于 three.js 使用 ES module（import map），浏览器禁止在 `file://`
> 下直接加载，必须通过本地 HTTP 服务访问（这与部署到 GitHub Pages /
> Vercel 等静态托管的方式一致）。不要直接双击 index.html。

端口冲突时可指定其它端口：`node serve.js 9000` → 打开 http://localhost:9000

## 物理模型

托卡马克轴对称磁场由两部分叠加：

- **环向场**（环形场线圈产生）：`B_φ(R) = B₀ · R₀ / R`，随大半径 1/R 衰减
- **极向场**（等离子体电流产生）：`B_θ(r) = Bp₀ · r / a`，其中 `Bp₀ = (a/R₀)·B₀/q`，由安全因子 q 导出

粒子运动用洛伦兹力 `a = (q/m)(v × B)`，四阶 Runge-Kutta 积分。
在轴对称场中粒子沿磁面螺旋运动并被约束——这正是托卡马克磁约束的核心物理。

## 可调参数

| 类别 | 参数 | 说明 |
|---|---|---|
| 装置 | R₀ 大半径 | 托卡马克大半径 (m) |
| 装置 | a 小半径 | 等离子体/真空室小半径 (m) |
| 装置 | B₀ 环向磁场 | 磁轴上环向场 (T) |
| 装置 | q 安全因子 | 磁轴处安全因子，控制螺旋缠绕 |
| 粒子 | 电荷 q | (C) |
| 粒子 | 质量 m | (kg) |
| 粒子 | 初始小半径 r₀ | 发射点离磁轴距离 (m)，须 < a |
| 粒子 | 平行速度 v∥ | 沿磁场方向初速 (m/s) |
| 粒子 | 垂直速度 v⊥ | 垂直磁场初速，决定回旋半径 (m/s) |
| 模拟 | 环向圈数 | 粒子绕环向转多少圈 |
| 模拟 | 每回旋周期步数 | 精度，越大越准但越慢 |

## 视图切换

鼠标拖拽自由旋转、滚轮缩放；右上角按钮一键切换机位：
**默认 / 俯视 / 侧视 / 正视**。

## 场景元素

- 半透明环形真空室（大半径 R₀、小半径 a）
- 环形场线圈（TF 线圈，环向 8 根立式环）
- 内部发光等离子体、中心螺线管、磁轴环（金色）
- 磁面螺旋线（青色渐变，展示磁面结构）
- 发光粒子 + 光晕 + 渐变轨迹（蓝紫 → 暖白）

## 结果卡片

发射点磁场 B、环向场 B_φ、极向场 B_θ、螺旋角、局部安全因子 q(r₀)、
回旋周期、回旋半径 ρ、约束指标 r_max/a（越接近 r₀/a 说明约束越好）、
能量误差（RK4 守恒精度）、步数 / 总时间。
