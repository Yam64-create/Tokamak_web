# 托卡马克粒子模拟 · Tokamak Particle Simulation

纯前端（Three.js + 本地物理引擎）的托卡马克带电粒子约束模拟。
浏览器本地完成全部物理计算，无需任何后端 / Python 服务。

磁场有两套数据源，可在左侧面板切换：

| 数据源 | 说明 |
|---|---|
| **GSFit 重建（ST40 #12050）** | 真实装置磁场：PF 线圈几何（11 组 / 364 根 filament）+ 逆平衡重建得到的极向磁通 ψ(R,Z)，含等离子体电流与被动结构贡献 |
| **解析示意模型** | 旧的参数化模型：`B_φ = B₀R₀/R`，`B_θ = Bp₀·r/a`，用于教学对比 |

## 运行方式

```bash
cd D:\VSCode\Tokamak_web-deploy
node serve.js            # 默认端口 8081
```

然后浏览器打开 **http://localhost:8081**

端口冲突时：`node serve.js 9000` → 打开 http://localhost:9000

也可以用 Python 起服务（不依赖 Node）：

```bash
python -m http.server 8000
```

> 由于 three.js 使用 ES module（import map），浏览器禁止在 `file://` 下
> 直接加载，必须通过本地 HTTP 服务访问（与部署到 GitHub Pages /
> Vercel 等静态托管的方式一致）。**不要直接双击 index.html。**
> 页面打开后会自动跑一次仿真，直接看到 ST40 装置与粒子轨迹。

## GSFit 数据是怎么来的

数据由 GSFit（Tokamak Energy 的 Grad-Shafranov 逆平衡重建工具）在
`D:\GSFit` 中离线重建得到，导出脚本为
`D:\GSFit\particle_bridge\export_web_gsfit_data.py`：

```
coil_data.json      → 11 组线圈，364 根 filament（R, Z, dR, dZ, I）
plasma_psi.npz      → 81×161 极向磁通网格
                    ↓
gsfit_data.js       → window.GSFIT_DATA（前端直接可用）
```

`GSFIT_DATA` 内容：

- `meta`：machine ST40、pulse 12050、time_ms 130
- `tf`：`R0 = 0.400 m`、`B_phi0 = 1.7952 T`、`R0Bphi0 = 0.7181 T·m`
- `equilibrium`：磁轴 `(0.51553, 0.00423) m`、`Ip = 422.8 kA`、LCFS `a = 0.1863 m`、Grad-Shafranov 偏差 `2.27e-6`
- `coils`：11 组线圈各自的电流与 filament 表
- `psi`：`R 0.01–1.01 m`、`Z −1–1 m`、网格步长 `0.0125 m`，共 13041 个值
- `surfaces`：5 层闭合磁面（ψ 等值线，各 96 点）
- `lcfs`：最后闭合磁面（96 点闭合折线）

## 物理实现（重点）

### 1. 极向场的 2π 因子

IMAS / GSFit 的 `profiles_2d/psi` 是**总极向磁通（Wb）**，不是 Wb/rad，
因此

```
B_R = -(1/(2πR)) ∂ψ/∂Z
B_Z = +(1/(2πR)) ∂ψ/∂R
```

漏掉 2π 会让极向场放大 6.28 倍（起始点 B_Z 会从 −0.075 T 误成 −0.471 T）。

### 2. ψ 与线圈场不能相加

ψ 已经包含线圈 + 等离子体 + 被动结构的总贡献，所以 `gsfit_field.js` 的策略是：

- ψ 网格**内**：用 ψ 梯度（含等离子体电流效应）
- ψ 网格**外**：用 364 根 filament 的毕奥-萨伐尔解（椭圆积分闭式）
- 二者**绝不叠加**

### 3. 插值必须是 C¹ 连续

初版用双线性插值，洛伦兹力在网格边界发生跳变，能量误差高达 1.74%。
改为 **Catmull-Rom 双三次插值**（值和导数都连续）后，同一工况误差降到
0.06%（60 步/回旋周期）。这是数值方法层面的关键修正。

### 4. 环向场

GSFit 只给标量约定 `R0*B_phi0`，不存 TF 几何，因此：

```
B_φ(R) = R0Bphi0 / R
```

磁轴处 `B_φ = 1.3929 T`。

### 5. 粒子运动

```
a = (q/m)(v × B)        四阶 Runge-Kutta
```

初速度由 `(v∥, v⊥)` 构造：平行分量沿局部 `B̂`，垂直分量取
`e_Z` 在垂直于 B 的平面上的投影（**不能**直接用 `e_φ` 当垂直方向，
B 本身几乎沿 `e_φ`，那样会把回旋运动吃掉）。

## 可调参数

| 类别 | 参数 | 说明 |
|---|---|---|
| 磁场 | 数据源 | GSFit 真实场 / 解析示意模型 |
| 装置 | R₀ 大半径 | GSFit 模式下锁定为磁轴位置 0.5155 m |
| 装置 | a 小半径 | GSFit 模式下锁定为 LCFS 0.1863 m |
| 装置 | B₀ 环向磁场 | GSFit 模式下锁定为磁轴环向场 1.3929 T |
| 装置 | q 安全因子 | GSFit 模式由真实磁场反算，输入仅作参考 |
| 粒子 | 电荷 q / 质量 m | 默认氘核 (1.6e-19 C / 3.34e-27 kg) |
| 粒子 | 初始小半径 r₀ | 发射点离磁轴距离，须 < a |
| 粒子 | 平行速度 v∥ | 沿磁场方向初速 (m/s) |
| 粒子 | 垂直速度 v⊥ | 垂直磁场初速，决定回旋半径 (m/s) |
| 模拟 | 环向圈数 | 绕环向转多少圈 |
| 模拟 | 每回旋周期步数 | 精度旋钮：30 → 1.7%，60 → 0.06% 能量误差 |

## 场景元素

GSFit 模式下：

- **PF 线圈**（真实几何）：364 根 filament 扫成细管，合并为**单次 draw call**
- 按线圈组分色（图例见左侧面板）：BVLB/BVLT 蓝、BVUB/BVUT 深蓝、
  DIVB/DIVT 橙、MCB/MCT 绿、PSHB/PSHT 灰、SOL 青
- **5 层嵌套磁面**（ψ 等值面旋转生成）+ **LCFS 等离子体**（红色）
- 真空室（LCFS 外扩 1.14 倍）
- 磁轴环（金色）、TF 线圈（示意 8 根立环，GSFit 无 TF 几何）
- 磁力线（沿真实磁场积分，二阶步进 4 mm）
- 发光粒子 + 光晕 + 渐变轨迹

解析模式下为旧的示意几何（Torus 真空室 + 8 根 TF 环）。

## 已知限制

- ST40 的 TF 线圈几何不在 GSFit 数据里，场景中的 8 根立环只是示意。
- 线圈按 filament 圆环建模，未做工程上的 D 形/斜接细节。
- ψ 网格分辨率 0.0125 m（约 15 个格点覆盖等离子体小半径），
  更细的网格需要重新导出 `plasma_psi.npz`。
- 被动结构（真空室涡流）只在 ψ 里体现，没有单独的电阻壁演化模型。
